# Pandy Donut Docs

Public product and support site for **Pandy Donut** / **Панда Пончик**. The character is **Панда Пончик**, racing through a donut-themed three-lane arcade run.

## Site content

- Uses Pandy Donut app assets: panda character, donuts, game background, icon, and logo.
- Keeps the raspberry-pink and mint palette consistent on `index.html`, `support.html`, `privacy.html`, and `terms.html`.
- Shows the approved Docs screenshots: launch art without a spinner, active gameplay with falling donuts and no Game Over or banner, and English settings.
- Provides localized support in 17 interface languages.

## Deployment

The static public site deploys from `main` through `.github/workflows/pages.yml`.
