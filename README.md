# donutVille Docs

Official website for **Pandy Donut** / **Pandy Donut**, an iOS arcade game starring Pandy.

## Main character

The game's main character is **Pandy** (**Панді**).

## Pages

- `index.html` — product landing page
- `support.html` — localized support in 17 languages
- `privacy.html` — privacy policy
- `terms.html` — terms of use

The site is static and deployed to GitHub Pages through
`.github/workflows/pages.yml`.
